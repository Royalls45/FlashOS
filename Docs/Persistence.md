# Persistence и режимы запуска

FlashOS различает два сценария:

1. **Live ISO + Persistence** — ISO запускается в live-режиме, а отдельное хранилище подключается способом, который должен поддерживаться конкретным образом и загрузчиком.
2. **Полноценная VM** — гостевая система устанавливается на отдельный виртуальный диск QCOW2, который затем используется повторно.

Найденный `persistence.dat` или backend из `ventoy.json` сам по себе не доказывает совместимость с прямым запуском ISO через QEMU. Приложение показывает найденные пути и явно оставляет статус совместимости неподтверждённым.

`persistence.bat` читается только как текст. В нём отмечаются потенциально опасные команды (`format`, `del`, `diskpart`, `powershell`, `shutdown` и другие), но скрипт не запускается.

Фактическая проверка Persistence должна выполняться отдельно:

1. Запустить гостевую систему.
2. Создать уникальный тестовый файл.
3. Корректно завершить гостевую систему.
4. Повторно запустить её с тем же хранилищем.
5. Проверить содержимое файла и настройки пользователя.

До завершения этого теста интерфейс не должен сообщать, что Persistence работает.
